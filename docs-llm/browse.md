# Browse Components

[← Index](README.md)

A curated visual showcase, not a component reference page. `docs/docs/browse.html`
is a `wui-bento` gallery of live, animated tiles that each link straight to one
component's own doc page (real `<a href>` navigation, works with middle-click).
It is not part of the sidebar `NAV` array (see [README](README.md)) — it is
reached from the docs homepage as a "browse" entry point, not a documented
component in its own right, so there is no markup to mirror here.

Tiles on the page and the pages they link to:

- Charts tile (2x2) → [Charts](charts.md)
- Heatmap tile (2x2) → [Heatmap](heatmap.md)
- Two 1x2 chart tiles → [Charts](charts.md)
- Calendar tile (6x3) → [Calendar](calendar.md)
- Kanban tile (6x3) → [Kanban](kanban.md)
- Date/time tile (2x2) → [Text Inputs & Fields](forms.md) (Date & Time section)
- Cards & Containers tiles (2x2, 1x2) → [Cards & Containers](containers.md)
- Badges & Chips tile (1x2) → [Badges & Chips](interactive.md)
- Buttons tile (1x1) → [Buttons](buttons.md)
- Progress tile (1x1) → [Progress](progress.md)
- Tables tile (2x2) → [Tables](tables.md)

If you are looking for the actual component markup for any of the above,
follow the link to that page's own `.md` file rather than this one.
