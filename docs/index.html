bolt Load Order (Critical)
warning
weoc-ui.js must load before the CSS
It applies the saved theme synchronously to prevent a flash of unstyled content (FOUC). Never flip this order. 
<head>
  <!-- 1. JS first — applies theme before paint -->
  <script src="https://cdn.atlascrisis.com/Shared/JS/weoc-ui.js"></script>

  <!-- 2. Core CSS barrel (imports all modules) -->
  <link rel="stylesheet" href="https://cdn.atlascrisis.com/Shared/CSS/weoc-ui/weoc-ui-core.css">

  <!-- 3. Optional add-ons -->
  <link rel="stylesheet" href="https://cdn.atlascrisis.com/Shared/CSS/weoc-ui/weoc-forms.css">
  <link rel="stylesheet" href="https://cdn.atlascrisis.com/Shared/CSS/weoc-ui/weoc-tables.css">

  <!-- 4. Google Fonts (Cairo + Material Symbols) -->
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cairo:wght@300;400;500;600;700;800&display=swap">
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200">
</head>
dark_mode Theme

Dark mode is resolved from localStorage synchronously when the JS parses. Toggle persists across page loads. On WebEOC Nexus, WUI.nativeTheme is true and theme-toggle buttons are hidden automatically.

Current Theme
—
// Programmatic API
WUI.getTheme()             // 'light' | 'dark'
WUI.setTheme('dark', { persist: true })
WUI.toggleTheme()

// Declarative (auto-wired by weoc-ui.js)
<button data-wui-theme-toggle>Toggle</button>

// Listen for changes
document.documentElement.addEventListener('wui:themechange', e => {
  console.log(e.detail.dark); // true | false
});
gavel WebEOC XML Constraint
error
Boolean data-wui-* attributes must use ="true" or =""
WebEOC's XML parser rejects bare boolean attributes. Always use the value form. 
<!-- CORRECT in WebEOC XML -->
<div class="wui-modal" data-wui-backdrop="true"></div>
<button data-wui-dismiss="">Close</button>

<!-- WRONG — fails in WebEOC XML -->
<div class="wui-modal" data-wui-backdrop></div>
<button data-wui-dismiss>Close</button>
