Components
Overlays
Drawer, modal, popover, and dropdown — all driven by WUI.open/close/toggle or declarative [data-wui-toggle] attributes.
info
WebEOC XML constraint
Boolean attributes must use ="" values: data-wui-backdrop="true", data-wui-dismiss="". Never bare attributes.

Full-viewport fixed overlay. Default slides from right. Add .start to slide from left. Add .has-overlay to dim the page. Controlled by WUI.open/close or [data-wui-toggle].

open_in_browserwui-popover

Floating contextual panel positioned near a trigger. Contains a menu list with wui-pop-actions + wui-pop-btn items.

Action menu popover

Driven entirely by data-attributes (no JS): data-wui-toggle="#id" on the trigger; on the target, data-wui-open-class="show" (the class WUI adds to reveal it), data-wui-anchor="bottom-end" (WUI positions it relative to the trigger), and data-wui-dismiss="" on the inner wrapper (any item click closes it).

<!-- Trigger -->
<button data-wui-toggle="#my-pop">Actions</button>

<!-- Target: open-class + anchor + dismiss drive the whole thing -->
<div id="my-pop" class="wui-popover"
     data-wui-open-class="show"      <!-- class WUI adds to reveal -->
     data-wui-anchor="bottom-end">   <!-- side-align: top/bottom/left/right + start/center/end -->
  <div class="wui-pop-actions" data-wui-dismiss="">   <!-- click any item → close -->
    <button class="wui-pop-btn">
      <span class="material-symbols-outlined">edit</span> Edit
    </button>
    <button class="wui-pop-btn danger">
      <span class="material-symbols-outlined">delete</span> Delete
    </button>
  </div>
</div>
<!-- wui-pop-btn colors: (default) | primary | warning | danger | success -->
arrow_drop_down_circlewui-dropdown

Select-like dropdown with a styled item list. Positioned relative to its wrapper. Toggle via [data-wui-toggle]; items can have icons.

Same three target attributes as the popover. Live inside a wui-dropdown-wrap so the trigger and menu stay grouped; data-wui-dismiss="" on the menu closes it when an item is picked.

codeOverlay JS API
// Open / close / toggle any overlay by element reference
WUI.open(panelEl, triggerEl)
WUI.close(panelEl)
WUI.toggle(panelEl, triggerEl)

// Events fired on the panel element
panelEl.addEventListener('wui:open', e => { /* e.detail.trigger */ })
panelEl.addEventListener('wui:close', e => { })

// WUI.anchor — position a floating element near a trigger
WUI.anchor(floatingEl, triggerEl, {
  side: 'bottom',      // 'top' | 'bottom' | 'left' | 'right'
  align: 'start',      // 'start' | 'center' | 'end'
  gap: 8,              // px offset from trigger
  margin: 8            // px from viewport edge
})

A specialized confirm dialog for closing event records (the body typically hosts a WebEOC embedview). Its overlay is display:none until visible is set. Distinct from the generic wui-modal above — fixed 480×560 dialog tuned for an embedded close-form.
