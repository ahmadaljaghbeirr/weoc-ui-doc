Cards & Forms
wui-card has three composable layers: surface modifiers, layout templates, and atom elements. Card groups, checkboxes, and radios follow.
schemaAnatomy

Every card is three strictly-separated layers: a surface (wui-card — chrome only), a template that arranges named regions (is-metric / is-record / is-item), and atoms (wui-card-*) that fill those regions. The maps below show which region is which.

Interactive card (.is-interactive)

is-interactive gives the hover gradient border; is-selected is the persistent active border; is-disabled dims and blocks pointer events. For real selection, drive it declaratively — no JS: data-wui-activate="true" + data-wui-group="<selector>" + data-wui-active="is-selected". Click a card below — selection roves (only one stays selected).

CSS-drawn checkmark. Wraps <input type="checkbox"> for native behavior. Use .is-disabled or <input disabled> for disabled state.

  <span class="wui-control-box"></span>

</label>
