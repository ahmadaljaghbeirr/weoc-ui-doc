Components
Maps
Chrome for map views: the canvas wrapper, an overlay control rail (zoom + basemap switcher), and a point popover. The map engine itself (Leaflet/ESRI) is yours to drop in.
info
Add-on module — load weoc-maps.css after the core barrel
Maps are not in weoc-ui-core.css. The map view is a placeholder box here; in production it holds your map engine's canvas.
mapwui-map-wrap & wui-map-view

wui-map-wrap is the positioned root; wui-map-view holds the map canvas. The control overlay is an absolutely-positioned child of the wrap.

map canvas (Leaflet / ESRI) mounts here 
<div class="wui-map-wrap">
  <div class="wui-map-view"><!-- map engine canvas --></div>
  <div class="wui-map-controls-overlay">
    <div class="wui-map-controls">
      <button class="wui-map-btn" data-wui-action="zoom-in">
        <span class="material-symbols-outlined">add</span>
      </button>
      <button class="wui-map-btn" data-wui-action="zoom-out">
        <span class="material-symbols-outlined">remove</span>
      </button>
    </div>
  </div>
</div>
layersBasemap switcher

wui-basemap-group pairs a toggle wui-map-btn with a collapsible wui-basemap-tools rail. Add open to the tools (and active to the toggle) via JS to reveal the options. wui-map-btn takes active for the selected state.

<div class="wui-basemap-group">
  <button class="wui-map-btn" data-wui-action="toggle-basemap">
    <span class="material-symbols-outlined">layers</span>
  </button>
  <div class="wui-basemap-tools open">   <!-- "open" toggled by JS -->
    <button class="wui-map-btn">Streets</button>
    <button class="wui-map-btn">Satellite</button>
    <button class="wui-map-btn">Terrain</button>
  </div>
</div>
location_onwui-map-point-popover

Floating card shown when a map point is clicked. Structure: accent bar → header (icon + titles + close) → divider → body rows → footer (badges left, actions right). display:none by default; JS positions and reveals it.
