Tier Colors
Agency activation-tier color extensions. Apply .tier-1 through .tier-4 to badges, chips, status dots, icon bubbles, callouts, banners, cards, and level bars to communicate EOC activation state.
emergencyTier System

The four tiers map to EOC activation levels. Token names follow the pattern --tier-N-color, --tier-N-light, --tier-N-muted, --tier-N-glow, --tier-N-text. All tokens are defined in agency-theme.css with full dark-mode remaps.

ClassColorActivation LevelTokens
.tier-1 Green Standby / Normal Operations --tier-1-*
.tier-2 Amber Partial Activation --tier-2-*
.tier-3 Red-Orange Full Activation --tier-3-*
.tier-4 Critical Red MACC Activated --tier-4-*
