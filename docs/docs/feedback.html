chat_bubblewui-callout

4-sided inline contextual notices. Lighter than a banner — use inside panel bodies, form flows, or documentation. 6 variants.

info
Primary callout
General informational notice with a title and body text.
info
Info callout
Contextual information the user should be aware of.
check_circle
Success callout
Operation completed. Record has been saved successfully.
warning
Warning callout
This action cannot be undone. Proceed with caution.
error
Danger callout
Critical constraint violated. Data could not be submitted.
help
Secondary callout
Low-priority note or tip for the user.
