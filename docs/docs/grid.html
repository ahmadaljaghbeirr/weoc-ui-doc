grid_4x4CSS Grid Utilities

Utility classes that apply display:grid with predefined column counts or auto-fill behavior.

wui-grid-{1–6} — fixed column count
<!-- Fixed column count: wui-grid-1 through wui-grid-6 -->
<div class="wui-grid wui-grid-3 wui-gap-3">
  <div>…</div>
  <div>…</div>
  <div>…</div>
</div>

<!-- Auto-fill responsive: wui-grid-auto -->
<div class="wui-grid wui-grid-auto wui-gap-3">…</div>

<!-- Fit to content: wui-grid-fit -->
<div class="wui-grid wui-grid-fit wui-gap-3">…</div>

<!-- Dense packing: add wui-grid-dense -->
<!-- Fill height: add wui-grid-fill-h -->
