more_horizTruncation & labels

wui-truncate clips to a single line with an ellipsis. Default width is 20ch; override per element with style="--wui-truncate: 30ch". The DOM text stays intact (clip is visual only) — pair with title for a hover tooltip. wui-label-text applies the secondary label color.

wui-truncate — this long string is clipped with an ellipsis 
<span class="wui-truncate" title="full text" style="--wui-truncate: 28ch">
  Long string clipped with an ellipsis
</span>
