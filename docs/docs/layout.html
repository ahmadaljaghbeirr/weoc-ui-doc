Layout
The app shell (wui-body-shell, wui-main-div, wui-container), then wui-split, wui-toolbar, wui-field-row, wui-bento, and scroll/fill primitives.
wysiwygApp shell

Every board nests the same way: body.wui-body-shell (full-height, overflow:hidden, flex column) → wui-main-div (padded flex column that fills the viewport) → a sticky wui-hdr-wrap plus a flex:1 content region (wui-split or wui-scroll-area) that takes the remaining height. wui-container is the Bootstrap-aligned max-width content column for non-shell pages.

Shell nesting
body.wui-body-shell — 100vh · overflow:hidden · flex column
.wui-main-div — padded flex column, fills the shell
.wui-hdr-wrap — sticky header (shrinks to content)
.wui-split / .wui-scroll-area — flex:1 content, fills remaining height
<body class="wui-body-shell">        <!-- 100vh · overflow:hidden · flex column -->
  <div class="wui-main-div">          <!-- padded flex column, fills the shell -->
    <div class="wui-hdr-wrap">…header…</div>        <!-- shrinks to content -->
    <div class="wui-split">…content…</div>          <!-- flex:1 — fills the rest -->
  </div>
</body>
wui-container — max-width content column

Centered column with responsive max-width breakpoints (576/768/992/1200/1400px), Bootstrap-aligned. wui-container-fluid stays full-width at every breakpoint. Side padding from --space-4.

.wui-container — centered, max-width per breakpoint
<div class="wui-container">…</div>        <!-- responsive max-width, centered -->
<div class="wui-container-fluid">…</div>  <!-- always full width -->
view_columnwui-split

CSS grid two-pane layout. Panel is the secondary pane; main is the primary. Add .panel-start to dock panel on the left. Column ratios via modifier classes; override with inline style="grid-template-columns: …".

Panel right (default) — ratio-3-1

.wui-split-panel

  <div class="wui-split-main">…main content…</div>
  <div class="wui-split-panel">…detail panel…</div>
</div>
Panel left (.panel-start)
.wui-split-panel
.wui-split-main 
<!-- Panel on the left -->

  <div class="wui-split-panel">…nav/sidebar…</div>
  <div class="wui-split-main">…content…</div>
</div>

ClassMain : PanelUse case

Collapsed state (.is-collapsed)

Animates the panel column to 0fr (320ms). Toggle with [data-wui-panel-close] or WUI.open/close.

<!-- Collapse the panel -->
<div class="wui-split ratio-3-1 is-collapsed">…</div>

<!-- Declarative: clicking this closes the split panel + clears active -->
<button data-wui-panel-close="#my-split">Close Panel</button>
