web_assetwui-hdr-wrap

Sticky board header. Structure: wui-hdr-wrap → wui-hdr-inner → wui-hdr-top (the row holding wui-hdr-left = icon + title, and wui-hdr-right = actions). An optional wui-hdr-tabs-wrap sits below wui-hdr-top, inside the same inner. The .centered variant turns wui-hdr-inner into a max-width card.

Centered variant (.centered)
